Atmosphere & Units

The standard atmosphere and the airspeeds you fly by — the reference conditions behind every other aero calculation.

What it shows
  • ISA T, p, density, speed of sound, viscosity, and the θ/δ/σ ratios at any altitude
  • Mach ↔ TAS ↔ EAS ↔ CAS conversions
  • Reynolds number for a chosen length
  • ISA-profile plots (T and ratios vs altitude)
How to use it
  • enter an altitude in m / ft / km / FL
  • add a speed (Mach / TAS / EAS / CAS) to convert it
  • add a length to get the Reynolds number
Method

ISA-1976 (geometric altitude → geopotential); compressible subsonic airspeed relations; Sutherland's law for viscosity. Pure Python — nothing to install.

Try it: FL350 at Mach 0.80 → ~461 KTAS but only ~272 KCAS — that gap is why jets fly "by CAS."

ISA-1976. Altitude is geometric (converted to geopotential internally). Airspeed relations are compressible subsonic (Mach < 1) on a standard day: TAS → EAS via √σ, CAS via the impact-pressure relation referenced to sea level. Viscosity via Sutherland's law. Pure Python -- no external dependencies.
